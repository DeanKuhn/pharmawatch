Pipeline

Each stage with real row counts. Units change along the way (reports, cases, drug rows, pairs), so the bars track only the dedup drop: distinct cases as a share of raw reports.

  1. DownloadFDA quarterly ZIPs
    90 quarters, 2004Q1–2026Q2
    FAERS column names changed over the years; all mapped to one set.
  2. RawParquet on R2
    24.8M reports
    100.5M drug rows
    Written once, never modified.
  3. DedupPython + DuckDB
    20.6M cases
    75.1M drug rows
    Latest version per case, per FDA rules; FDA-deleted cases removed.
  4. Stagingdbt
    75.1M drug rows
    61.3M reaction rows
    Typed dates and numbers, cleaned drug names kept beside the raw ones (003).
  5. Intermediatedbt
    139,460 drug names → 11,954 drugs
    20.6M cases in the 2×2
    Names resolved to RxNorm ingredients, contingency counts per pair.
  6. Martsdbt
    61.3M fact rows
    2.85M pairs scored
    16.1M pair-quarters
    Star schema plus IC/IC025, with and without lawyer-filed reports.
  7. ServingDuckDB file
    0.38 GB, 3 tables
    Exported from the 10.9 GB warehouse and copied to the server.
  8. WebFastAPI on Hetzner
    this site
    Jinja templates over a read-only connection.

Serving schema

The three tables this site reads, copied out of the warehouse into a small DuckDB file. Joined on identity_key, the RxNorm ingredient set that defines a drug. Key columns only, mart_signals has 22 in total. 

erDiagram
  dim_drug ||--o{ mart_signals : "identity_key"
  mart_signals ||--|{ mart_pair_quarters : "identity_key, reaction_pt"

  dim_drug {
    varchar drug_key PK "surrogate"
    varchar identity_key UK "sorted RxNorm ingredients"
    varchar drug_label "most-reported name"
    bigint n_signals "pairs with ic025 > 0"
  }
  mart_signals {
    varchar identity_key PK, FK
    varchar reaction_pt PK "MedDRA term"
    bigint a "2x2 counts a, b, c, d"
    double ic025 "rank score"
    double ic025_nolw "without lawyer reports"
    double pct_lw "lawyer-reported share"
    date peak_quarter
  }
  mart_pair_quarters {
    varchar identity_key PK, FK
    varchar reaction_pt PK, FK
    date report_quarter PK
    bigint n_cases
    bigint n_cases_nolw
  }

One drug, 390 spellings

Reporters type drug names freely. This is how primary-suspect reports for hydrocodone/acetaminophen collapse into one drug. All counts were queried and can be produced again.

  1. Reported name
    390 spellings
    • VICODIN
    • NORCO
    • HYDROCODONE + APAP
    • HYDROCODONE BITARTRATE;ACETAMINOPHEN UNK
    • NORCO (UNKNOWN) (WATSON LABORATORIES)
    • LORCET (ACETAMINOPHEN/HYDROCODONE)
    …and 384 more.
  2. Active ingredients
    2 strings
    • ACETAMINOPHEN\HYDROCODONE BITARTRATE
    • ACETAMINOPHEN\HYDROCODONE
    FDA fills this field on 86% of these rows. The other 14% (Vicodin, Lortab, …) come from a lookup: a cleaned name that maps to one ingredient string at least 95% of the time.
  3. RxNorm ingredient
    2 ingredients
    • ACETAMINOPHEN → 161
    • HYDROCODONE BITARTRATE → 5489
    • HYDROCODONE → 5489
    Split on \, then each piece is matched through the RxNav API. Salt forms resolve to the base ingredient.
  4. Drug
    1 identity
    • rxcui:161|rxcui:5489
    40,447 primary-suspect reports, 150 signals. See the drug page.

From the mess log

Four of the 43 (and more to come) data problems logged while building, each with a real example. The full list is at docs/mess_log.md.

Two records on one line
DRUG11Q2.TXT line 322,967
25 fields, 12-column header
A missing line break glued two drug records together. The parser splits overlong lines into header-sized chunks.
Junk in numeric fields
dose_amt: "554 MILLION", "18-54", "DF"
age:      "163/6", "N/A"
Cast with try_cast to null. A bare decimal cast was also silently rounding 0.0005 to 0.001, so doses are stored as double.
Pfizer and Moderna merged
TOZINAMERAN (Pfizer)  48,359 rows
ELASOMERAN (Moderna)  30,651 rows
→ one RxNorm ingredient
Both map to the same RxNorm ingredient, so a dbt seed file maps 18 biologic pieces to product-level RxNorm codes instead.
One field, several drugs
prod_ai: "AZITHROMYCIN OR METHOTREXATE SODIUM"
81 strings, 9,638 rows
FDA lists every candidate when a name is ambiguous. These rows stay in the background counts but are never scored as a drug.
