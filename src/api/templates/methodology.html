Pipeline

Each stage with real row counts. Units change along the way (reports, cases, drug rows, pairs), so the bars track only the dedup drop: distinct cases as a share of raw reports.

  1. DownloadFDA quarterly ZIPs
    90 quarters, 2004Q1–2026Q2
    FAERS column names changed over the years; all mapped to one set.
  2. RawParquet on R2
    24.8M reports
    100.5M drug rows
    Written once, never modified.
  3. DedupPython + DuckDB
    20.6M cases
    75.1M drug rows
    Latest version per case, per FDA rules; FDA-deleted cases removed.
  4. Stagingdbt
    75.1M drug rows
    61.3M reaction rows
    Typed dates and numbers, cleaned drug names kept beside the raw ones (003).
  5. Intermediatedbt
    139,460 drug names → 11,954 drugs
    20.6M cases in the 2×2
    Names resolved to RxNorm ingredients, contingency counts per pair.
  6. Martsdbt
    61.3M fact rows
    2.85M pairs scored
    16.1M pair-quarters
    Star schema plus IC/IC025, with and without lawyer-filed reports.
  7. ServingDuckDB file
    0.38 GB, 3 tables
    Exported from the 10.9 GB warehouse and copied to the server.
  8. WebFastAPI on Hetzner
    this site
    Jinja templates over a read-only connection.
