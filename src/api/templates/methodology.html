Pipeline

Each stage with row counts.

  1. DownloadFDA quarterly ZIPs
    90 quarters, 2004Q1–2026Q2
    FAERS column names changed over the years, all mapped to one set.
  2. RawParquet on R2
    24.8M reports
    100.5M drug rows
    Written once, never modified.
  3. DedupPython + DuckDB
    20.6M cases
    75.1M drug rows
    Latest version per case, FDA-deleted cases removed.
  4. Stagingdbt
    75.1M drug rows
    61.3M reaction rows
    Typed dates and numbers, cleaned drug names kept beside the raw ones.
  5. Intermediatedbt
    139,460 drug names → 11,954 drugs
    20.6M cases in the 2×2
    Names resolved to RxNorm ingredients, contingency counts per pair.
  6. Martsdbt
    61.3M fact rows
    2.85M pairs scored
    16.1M pair-quarters
    Star schema plus IC/IC025, with and without lawyer-filed reports.
  7. ServingDuckDB file
    0.38 GB, 3 tables
    Exported from the 10.9 GB warehouse and copied to the server.
  8. WebFastAPI on Hetzner
    this site
    Jinja templates over a read-only connection.

Reporters type drug names freely. This is how primary-suspect reports for hydrocodone/acetaminophen collapse into one drug.

  2. Active ingredients
    2 strings
    • ACETAMINOPHEN\HYDROCODONE BITARTRATE
    • ACETAMINOPHEN\HYDROCODONE
    FDA fills this field on 86% of these rows. The other 14% (Vicodin, Lortab, …) come from a lookup: a cleaned name that maps to one ingredient string ~95% of the time.

    2 ingredients
    • ACETAMINOPHEN → 161
    • HYDROCODONE BITARTRATE → 5489

    Split on \, then each piece is matched through the RxNav API. Salt forms resolve to the base ingredient.
  4. Drug
    1 identity

    40,447 primary-suspect reports, 150 signals. See the drug page.

From the mess log

Four of the 43 (and more to come) data problems logged while building, each with a real example. The full list is at docs/mess_log.md.

Two records on one line
DRUG11Q2.TXT line 322,967
25 fields, 12-column header
A missing line break put two drug records into one line. The parser splits these oversized lines into header-sized chunks.
Junk in numeric fields
dose_amt: "554 MILLION", "18-54", "DF"
age:      "163/6", "N/A"
Cast with try_cast to null. A bare decimal cast was also silently rounding 0.0005 to 0.001, so doses are stored as double.
Pfizer and Moderna merged
TOZINAMERAN (Pfizer)  48,359 rows
ELASOMERAN (Moderna)  30,651 rows
→ one RxNorm ingredient
Both map to the same RxNorm ingredient, so a dbt seed file maps 18 biologic pieces to product-level RxNorm codes instead.
One field, several drugs
prod_ai: "AZITHROMYCIN OR METHOTREXATE SODIUM"
81 strings, 9,638 rows
FDA lists every candidate when a name is ambiguous. These rows stay in the background counts but are never scored as a drug.

Scoring one pair

Every drug–reaction pair gets a 2×2 table of case counts over all 20.6M cases. Same drug as above, its top signal: dependence.

dependenceother reactions
hydrocodone/APAPa20,775b19,668
other drugsc34,035d20,510,241
  1. Expected, if drug and reaction were unrelated
    (a+b)(a+c) / N = 40,443 × 54,810 / 20,584,719 = 107.7
  2. IC (Information Component): how many times more often than expected, in log₂
    log₂((a+0.5) / (expected+0.5)) = log₂(20,775.5 / 108.2) = 7.585
  3. IC025: lower bound of the 95% credibility interval
    IC − 3.3(a+0.5)−1/2 − 2(a+0.5)−3/2 = 7.585 − 0.023 = 7.562

Why rank by IC025, not PRR

The original signal calculation, PRR, is a ratio, and small counts explode it. The +0.5 in IC pulls small pairs towards zero, so with only 3 cases, IC can never exceed ~2.8.

Lawyer bursts

Litigation floods FAERS with real but stimulated reports. Ranitidine was recalled in 2019–2020 over a possible carcinogen, and cancer reports followed the lawsuits. These are flagged, not dropped.
